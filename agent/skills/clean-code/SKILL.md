# Clean Code Skill

When asked to clean up or format code, follow these rules:

1. Follow and respect the existing comments.
2. Keep the code clean (removing dead code, consistent formatting, etc.).
3. Strictly avoid using any emojis in the code or comments.
4. Remove any unnecessary code and unused dependencies.
